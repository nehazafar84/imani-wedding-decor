# Photographic concept assets

Generated with the built-in image generation tool. These are AI photographic concepts, not documentary photographs of ICC Wales, Cardiff City Hall or St Mellons, and not verified Imani stock. Customer and owner interfaces identify this limitation. Original generated PNGs are retained in the Codex generated-images folder; the deployable WebP assets preserve transparency and are compressed for the website. No paid external image library is used.

The catalogue JSON maps product codes to these default assets. Approved images supplied through the owner dashboard override defaults; existing visibility and sort order still come from Supabase. Tables are complete photographic cutouts; when replacing these defaults, supply a matching complete table image, or adjust the table overlay layout for standalone centrepiece cutouts.
